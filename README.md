# C and C++ Practice Questions 🚀

Welcome to my repository! This project contains a collection of practice programs written in **C and C++**. I created this repository to track my coding journey, practice fundamental programming concepts, and build strong logic.

## ⚠️ Important Note: Turbo C Environment

All the programs in this repository were originally written, compiled, and tested using the **Turbo C / Turbo C++** compiler. 

Because of this, you might notice some legacy Turbo C specific functions and headers in the code, such as:
- `#include <conio.h>`
- `clrscr()` (to clear the console screen)
- `getch()` (to hold the output screen)
- `void main()` (instead of the standard `int main()`)

**Note for Modern Compilers:** If you are trying to run this code on modern compilers like GCC, MinGW, or IDEs like VS Code, you will need to remove `<conio.h>`, `clrscr()`, `getch()`, and change `void main()` to `int main()` to avoid compilation errors.

## 🛠️ How to Run

To run these programs exactly as they are, it is recommended to use:
- **Turbo C++** IDE
- **DOSBox** (if you are running Turbo C on modern Windows, Mac, or Linux)
